# MiniCinema API

A simple REST API for managing movies using FastAPI and PostgreSQL.

## Technologies
- Python 3.12
- FastAPI
- PostgreSQL 16
- Docker Compose

## Run

```bash
bash scripts/deploy.sh
```

API documentation: http://localhost:8000/docs

## Tests

```bash
bash scripts/check.sh
bash scripts/persistence-check.sh
```
